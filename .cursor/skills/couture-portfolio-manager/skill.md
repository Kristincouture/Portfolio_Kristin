# Couture Portfolio Manager

Whenever I finish a new design, such as a silk painting, ceramic piece, couture dress, or other portfolio-ready creation:

1. Use the GitHub MCP workflow to upload my project changes.
2. Create a professional commit message that starts with `Portfolio Update:`.
3. Clearly describe the specific artwork or design added in that update.
4. Keep the message concise and polished, suitable for a public portfolio history.

Commit message format:

`Portfolio Update: Added [specific art/design piece] to the portfolio`
